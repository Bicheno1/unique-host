# Unique Host engine — CCM engine + databases + character.json loader

The full engine (Cognitive Coherence Model, trimmed down for text
roleplay — see `chemical_system_docs/` for the original design). It runs
standalone, with no character loaded (it uses neutral defaults), and it
exposes the bridge for loading a real `character.json` (generated by the
compiler package, or written by hand).

**Language: English only.** The engine parses English text (spaCy
`en_core_web_sm`) and uses an English lexicon. Input in other languages is
not understood.

```
fullsystem/
├── motors/        ← CycleManagerV5 (the main orchestrator), core_identity
├── engines/       ← mental engine and somatic engine
├── systems/       ← memory, chemistry, vitality, plasticity, mental state
├── layers/        ← emotion, muscle tone, processing mode
├── core/          ← marker parser, response matrix (16 cells), phrase bank,
│                    construction_matcher (NLP/spaCy)
├── output/        ← final sentence construction
├── db/            ← ALL the engine's databases (concepts, lexicon,
│                    somatic/mental axes, sounds, etc.)
├── character/     ← injector.py, exporter.py, memory_seed.py — the bridge
│                    between a character.json and this engine
├── tools/         ← generators for the large lexicons (dev-only)
├── tests/         ← regression tests
├── agent.py       ← test CLI (no Gradio, no real character)
└── chemical_system_docs/  ← original design of the chemical system (CCM)
```

## Quick start

```bash
pip install -r requirements.txt
python -m spacy download en_core_web_sm
python -c "import nltk; nltk.download('wordnet'); nltk.download('omw-1.4')"
```

## About the databases

They do not need to be "emptied": they are already free of any data specific
to a test character. What they contain (`db_concepts.py`, `db_lexicon.py`,
etc.) is base vocabulary that **any** character needs for the engine to work
— it is not Delia's data or that of any other test. A character's own data
(family names, pets, concepts with their own weight such as "monster") live
**only** in its `character.json`, and are loaded into memory (they are not
written to these files) when calling
`character/injector.py::inject_character()`.

## Loading a character

```python
import json
from character.injector import inject_character

with open("character.json", encoding="utf-8") as f:
    character_data = json.load(f)

ccm, identity = inject_character(character_data)
state = ccm.process(text='"Angry" Shut up <<Storming off>>')
```

`spacy`, `nltk` and `lemminflect` are used by the live engine
(`core/construction_matcher.py` and `motors/cycle_manager_v5.py`); they are
not just for the tools in `tools/`. See `requirements.txt`.
